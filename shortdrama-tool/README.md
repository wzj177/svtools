## 📖 项目简介

**短剧智剪**是一款纯本地离线运行的桌面端工具，专为抖音短剧分销、国产短剧跨境出海创作者设计。提供双语字幕自动生成、高能片段智能切片、版权风险前置自检、双平台规格一键导出等核心功能。

### 核心定位
- ✅ **全程合规**：仅处理用户自有商用授权视频素材
- ✅ **本地离线**：所有音视频处理均在本地完成，不上传云端
- ✅ **轻量化**：基于 Tauri + Rust，安装包小于 15MB
- ✅ **双平台适配**：一键输出抖音/TikTok 双规格成片

### 适用场景
- 国内正版短剧二创切片
- 国产短剧 TikTok 双语分发
- 影视合规解说批量字幕制作

## ✨ 特性

### 1. 双语字幕自动化
- 短剧台词智能断句算法
- 中英时间轴批量对齐（准确率≥96%）
- 短剧爽文台词本土化润色
- 专属双语分屏字幕模板

### 2. 智能高能切片
- 基于画面突变、音频情绪、台词冲突点多维特征识别
- 自动分割 15-60 秒钩子片段（有效率≥90%）
- 本地 CPU 轻量推理，低配电脑流畅运行

### 3. 版权风险自检
- 离线音视频特征指纹提取
- 外网侵权短剧特征本地比对
- 风险分级提示 + 合规报告生成
- 无授权片段识别准确率≥93%

### 4. 双平台合规输出
- 抖音 9:16 竖屏、TikTok 海外标准一键切换
- 批量封面、标题、标签自动生成
- 适配抖音开放平台投稿接口

### 5. 三层合规隔离体系
- **技术隔离**：全素材本地渲染，服务器不存储任何音视频
- **流程隔离**：强制合规声明弹窗，记录操作日志
- **协议隔离**：用户协议明确侵权责任归属

## 🚀 快速开始

### 环境要求
- Node.js >= 18.x
- Rust >= 1.70
- pnpm >= 8.x (推荐)

### 安装依赖

```bash
cd shortdrama-tool

# 安装前端依赖
pnpm install

# 确保 Rust 环境正常
rustc --version
cargo --version
```

### 开发模式运行

```bash
# 启动开发服务器 (同时运行前端和 Tauri)
pnpm tauri dev
```

### 构建发布版本

```bash
# Windows
pnpm tauri build

# macOS
pnpm tauri build

# Linux
pnpm tauri build
```

构建完成后，安装包位于 `src-tauri/target/release/bundle/` 目录。

## 🎯 功能模块详解

### 工作台 (Workspace)
- 功能入口导航
- 首次使用强制合规声明确认
- 项目快捷入口

### 双语字幕 (Subtitle)
1. 批量导入视频素材
2. 自动提取音频轨道
3. Whisper 语音识别生成时间轴
4. AI 翻译 + 短剧台词润色
5. 导出独立 SRT 字幕文件

### 智能切片 (Clip)
1. 设置切片参数 (时长范围、灵敏度)
2. 多模态特征分析 (画面/音频/台词)
3. 自动标记冲突点、情绪高点
4. 预览并选择保留片段
5. 批量导出独立视频文件

### 版权自检 (Copyright)
1. 导入待检测视频
2. 提取画面 pHash + 音频指纹
3. 比对外网侵权特征库
4. 生成风险等级报告
5. 高风险片段定位标记

### 批量导出 (Export)
1. 选择目标平台 (抖音/TikTok/双平台)
2. 配置输出参数 (分辨率/帧率/编码/码率)
3. 自动生成封面、标签
4. 批量渲染输出
5. (可选) 调用抖音开放 API 自动上传

## ⚖️ 合规说明

### 严格禁止的功能
本项目**绝不开发、不集成**以下功能：
- ❌ 各平台视频解析、下载、去水印接口
- ❌ 规避平台查重的 MD5 修改、画面魔改工具
- ❌ 外网短剧素材资源库、搬运培训
- ❌ 云端存储用户完整音视频的 SaaS 服务

### 合规使用承诺
使用本工具即表示您同意：
- ✓ 仅使用已取得商用授权的正版短剧素材
- ✓ 仅通过抖音官方分销渠道获取片源
- ✓ 不将工具用于任何形式的侵权搬运行为
- ✓ 自行承担因违规使用导致的法律责任

### 免责条款
